# xAI SuperGrok

Use a SuperGrok or X Premium subscription with the `xai-supergrok` model route. No API key is needed. The built-in `xai` route stays unchanged.

## Sign in

1. Select **Sign in** below.
2. Open the verification page, enter the code, and approve sign-in.
3. Select an `xai-supergrok/...` model to start chatting.

## Usage

After sign-in, **Grok usage** appears above **Settings** in the sidebar. It does not depend on the selected model. The percentage shows used subscription credits. Select the indicator to see billing details.

A collapsed sidebar rail shows only the ring icon. Its tooltip shows the percentage. Windows desktop hides the indicator when the sidebar is fully collapsed.

Usage readings are cached for 2 minutes. The **Usage** section below also shows subscription credits and billing details. Listed model prices are API prices, not subscription usage.

## Account controls

- **Refresh models** updates the model list.
- **Sign out** removes local credentials. It does not revoke the token at xAI.
