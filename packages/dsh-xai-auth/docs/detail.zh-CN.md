# xAI SuperGrok

通过 `xai-supergrok` 模型路由使用 SuperGrok 或 X Premium 订阅，无需 API 密钥，不影响内置的 `xai` 路由。

## 登录

1. 在下方选择 **登录**。
2. 打开验证页面，输入验证码并批准登录。
3. 选择 `xai-supergrok/...` 模型，开始对话。

## 用量

登录后，侧栏的 **设置** 上方会显示 **Grok 用量**，不受当前模型选择影响。百分比表示已用订阅额度，点击可查看账单详情。

侧栏收为窄栏时仅显示环形图标，悬停提示显示百分比。Windows 桌面版完全收起侧栏时，用量控件也会隐藏。

用量结果缓存 2 分钟，下方的 **用量** 区域也可查看订阅额度和账单详情。模型标价是 API 价格，不代表订阅用量。

## 账号操作

- **刷新模型**：更新模型列表。
- **退出登录**：删除本地凭据，不会撤销 xAI 端的令牌。
