# M-PTC 与 M-Creator

两个使用 Exa MCP 替代原生 `web_search` 和 `web_fetch` 工具的代理预设，不改变内置预设。

## 选择预设

启用本插件组合后，新建会话并选择预设：

| 预设          | 用途                                                               |
| ------------- | ------------------------------------------------------------------ |
| **M-PTC**     | 基于内置 `ptc`，保留 PTC 工具呈现，禁用工作流工具。                |
| **M-Creator** | 基于内置 `cordis`，用于编写插件和预设，启用 Creator 和工作流工具。 |

已经运行的会话保持原有组合。

## Exa 访问

启动 dsh 前，在其进程环境中设置 `EXA_API_KEY`。可以使用 `$DSH_HOME/.env`，或在启动 dsh 的 shell 中设置。修改后需要重启 dsh，不要在聊天消息中发送密钥。

每个预设连接 `https://mcp.exa.ai/mcp`，以 `mcp__exa__*` 名称提供 Exa 工具。同一预设的会话共用该预设的连接。

Exa 连接失败时，预设可能仍处于启用状态，但没有搜索工具。请检查 dsh Host 日志中的认证或连接错误。
